# عالمنا الصغير ❤️

هدية تفاعلية بالعربي المصري، مبنية بـ React وVite وTypeScript. كل التفاصيل قابلة للتعديل من ملفات المحتوى من غير ما تغيّري مكوّنات الموقع.

## تشغيل الموقع

```bash
npm install
npm run dev
```

لفحص أنواع TypeScript:

```bash
npm run typecheck
```

إنشاء نسخة إنتاج محلية ومعاينتها:

```bash
npm run build
npm run preview
```

الموقع static بالكامل؛ مفيش backend أو حسابات. فتح الهدايا بيتحفظ على المتصفح الحالي. لو المتصفح مسح بيانات الموقع أو اتفتح على جهاز تاني، ابدئي التجربة من جديد على الجهاز ده.

## تعديل الحكاية

- افتحي `src/content.ts` لتغيير اسم صاحب الرسالة واسمها، والرسائل الست القصيرة، والأسباب الاثني عشر، وصور الألبوم، والاختبار، ووعدنا لبعض، ورسالة الختام.
- لتغيير صورة ذكرى، ضيفي الصورة داخل `public/assets/photos/`، وبعدها اكتبي مسارها في `src/content.ts` بهذا الشكل: `/assets/photos/our-photo.webp`. ضيفي عنوانًا ووصفًا عربيًا يشرح الصورة، وتاريخًا فقط لو كان حقيقيًا. لما تسيبي `src` فاضي، تظهر رسمة مكانها. ممكن تضيفي `thumbnailSrc` اختياريًا لو عايزة صورة مصغّرة أخف للألبوم، مع إبقاء `src` للصورة الكاملة.
- الاختبار فيه 10 أسئلة اختيار من متعدد، وممكن تختار أكتر من إجابة لكل سؤال. تُحفظ الإجابات على جهازها. زر «ابعتيلي إجاباتك» يفتح مسودة بريد إلى العنوان الموجود في `story.quizAnswersEmail` مع الإجابات مكتوبة؛ هي تضغط «إرسال» بنفسها. ده مجاني ولا يحتاج backend، لكن لازم يكون عندها تطبيق بريد أو إعداد mailto في المتصفح.
- عدّلي سجل الذكرى نفسه لإضافة الصور أو حذفها أو تعديل العناوين والتعليقات والتواريخ. كل سجل محتوى له `id` ثابت خاص به.
- الأسماء تبدأ افتراضيًا بـ«حبيبك» و«حبيبتي». اكتبي اسمين حقيقيين في `story.names` لما تكوني جاهزة.
- المزيكا مقفولة افتراضيًا. ضيفي ملف MP3 مرخّصًا أو تملكي حق استخدامه إلى `public/assets/music/`، ثم اكتبي مساره في `musicSrc`. يظهر زر الصوت تلقائيًا حين يكون هناك مسار.
- غيّري `story.finalLetter` لرسالتك الشخصية. اسم المرسل المستخدم كتوقيع مأخوذ من `story.names.sender`.

استخدمي صور WebP أو AVIF مضغوطة ومقاسها قريب من المقاس الظاهر على الشاشة لتسريع الألبوم. راجعي كل العينات قبل الإهداء حتى تعكسي الوقائع الحقيقية لعلاقتكم.

## النشر لاحقًا

مخرجات `npm run build` موجودة داخل `dist/`؛ ارفعي هذا المجلد إلى استضافة static. خيارا النشر المدعومان في دليل المشروع:

- **Vercel:** اربطي مستودع المشروع أو ارفعي مجلد المشروع. استخدمي `npm run build` كأمر بناء و`dist` كمجلد الإخراج.
- **Netlify:** اربطي المستودع أو ارفعي المشروع. استخدمي `npm run build` كأمر بناء و`dist` كمجلد النشر.

استخدمي رابط HTTPS للمشاركة. الصور والمحتوى الشخصي موجودان في ملفات الموقع الثابتة، ورابط المشاركة وحده لا يقيد المشاهدة.
